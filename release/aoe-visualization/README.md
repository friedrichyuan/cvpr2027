# AoE-Visualization

基于 [Rerun](https://rerun.io/) 的 Open-AoE 数据可视化浏览器。

## 功能规划

- **视频 + MANO 叠加**：ego-centric 视频上叠加 MANO 手部网格
- **3D 相机轨迹**：世界坐标系下的相机运动可视化
- **原子动作 Timeline**：交互式时间轴，显示双语动作描述
- **数据筛选**：按场景/动作类别/质量指标过滤 segments

## 技术选型

- **Rerun SDK** (Python): 3D + 时序数据可视化
- **依赖**: `rerun-sdk`, `numpy`, `opencv-python`
