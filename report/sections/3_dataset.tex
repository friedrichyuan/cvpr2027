\section{Open-AoE Dataset}

\subsection{Data Collection System Overview}

Open-AoE data is collected using the AoE system~\cite{aoe2026}, which leverages consumer-grade smartphones paired with an ergonomic magnetic neck mount ($<\$20$ per user). The system comprises a cross-platform mobile application (Android/iOS) for real-time sensor calibration and video capture, and a distributed edge-cloud architecture for scalable data processing. We refer readers to~\cite{aoe2026} for detailed system design.

\subsection{Data Selection and Quality Control}

From the full AoE data pool, we curate a 2,000-hour subset for open-source release based on three quality gates:

\begin{itemize}
    \item \textbf{Prediction validity coverage}: Segments where the MANO hand reconstruction achieves $>$80\% valid frame ratio are retained, ensuring reliable hand pose annotations.
    \item \textbf{Inverse kinematics failure rate}: Segments with IK failure rate $<$5\% during retargeting to the 28D joint space are selected, ensuring downstream usability.
    \item \textbf{Camera trajectory continuity}: Segments exhibiting continuous, smooth camera trajectories (no abrupt jumps $>$10cm between consecutive frames) are prioritized.
\end{itemize}

A final 5\% random human inspection verifies annotation accuracy and filters edge cases (severe occlusion, extreme lighting).

\subsection{Annotation Pipeline}

Each segment contains the following annotations produced by the AoE cloud pipeline~\cite{aoe2026}:

\begin{itemize}
    \item \textbf{Atomic action segmentation}: Qwen3-VL-235B-A22B~\cite{qwen2025vl} segments videos into semantically labeled atomic clips, with human-in-the-loop verification to correct VLM hallucinations.
    \item \textbf{Bilingual captions}: Each atomic action is described in both Chinese and English, providing a unique resource for cross-lingual VLA research.
    \item \textbf{MANO hand reconstruction}: HaWoR~\cite{hawor2025} recovers 3D MANO~\cite{mano2017} meshes, metric-scaled and transformed to world coordinates via SLAM, with sliding-window optimization enforcing temporal consistency.
    \item \textbf{Hand keypoints}: 21-joint hand keypoints extracted from the MANO reconstruction.
    \item \textbf{Camera trajectory}: MegaSAM~\cite{megasam2024} estimates 6-DoF camera poses with re-tuned robust kernels for handheld scenarios.
\end{itemize}
