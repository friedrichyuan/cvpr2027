# AoE-Visualization runtime dependencies (all REQUIRED).
#
# The intended/required rendering backend is the high-quality offscreen OpenGL
# hand-mesh renderer (director-colored, smooth-shaded MANO surface). It needs the
# GL stack below AND a working EGL/OpenGL context (a GPU box with EGL drivers, or
# an equivalent offscreen GL setup). Headless rendering uses PYOPENGL_PLATFORM=egl,
# which the tool sets automatically.
#
# Core (numerics + video/image I/O and drawing):
numpy>=1.17
opencv-python>=4.2
#
# OpenGL hand-mesh renderer (required backend):
pyrender>=0.1.45
trimesh>=3.23
PyOpenGL>=3.1
#
# System prerequisites (not pip-installable):
#   - EGL / OpenGL drivers for offscreen rendering (typically a GPU box).
#   - ffmpeg (optional system binary) is used to transcode the output to H.264;
#     without it the tool falls back to the OpenCV mp4v writer.
#
# Note: a pure-NumPy mesh fallback exists in the code as a safety net if the GL
# context cannot be created, but it is a DEGRADED path (flat-shaded, lower
# quality) and is not the approved/intended look. The MANO model itself is
# vendored as pure-NumPy .npz under assets/mano/, so no deep-learning framework
# is needed.
